> A fast, responsive, and visually engaging e-commerce storefront for children's educational toys, festive gift hampers, and sweet treats—featuring an integrated interactive recommendation assistant (**ToyBot**).

---

## 🌟 Key Highlights

* **Modern Responsive UI:** Built with semantic HTML5 and modern CSS (CSS Grid, Flexbox, custom design tokens, and smooth scrolling transitions).
* **Curated Product Collections:**
  * **Educational Toys:** Age-graded building blocks, sensory puzzles, and train sets.
  * **Gift Hampers:** Birthday bundles, craft kits, and illustrated storybook packs.
  * **Sweet Treats & Confectionery:** Kid-safe chocolates, gummies, and butter cookies.
* **Kids Zone Experience Gallery:** A lifestyle media showcase highlighting safe play and joyful child development.
* **Interactive ToyBot Assistant:**
  * Context-aware suggestion engine recommending products by age bracket (`0-2`, `3-5`, `6+`) and budget (`Under ₹500`).
  * Quick-action intent chips for friction-free recommendations.
* **Dynamic Shopping Cart Micro-interaction:** Real-time visual feedback with cart counter state management.
